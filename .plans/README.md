# .plans/ — per-milestone notes and rollup tables

One `mN-NNN-notes.md` file per landed issue. Each note pins:

- what code + docs the commit added,
- which design decision the commit witnesses,
- the paideia-as conformance checklist for the new function(s),
- what M(N+1) is scheduled to build on top.

See `STATUS.md` in the repo root for the milestone rollup that
consumers of this repo read; the per-milestone notes here are the
implementer-facing detail.
